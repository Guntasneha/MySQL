INTRODUCTION TO TRIGGERS
------------------
A trigger is a special type of stored program that authomatically executes(fires) in a response to the specific event. INSER,UPDATE,DELETE occurring on a specified table. unlike a stored procedure. a trigger never called directly.

General syntax
-----------
DELIMITER //
CREATE TRIGGER trigger_name
{BEFORE|AFTER}{INSERT|UPDATE|DELETE}
ON table_name
FOR EACH ROW
begin
    --- trigger logic
    -- use new column name for inserted/updated values
    -- use OLD.column_name for delete/previous values
END //
DELIMITE ;
